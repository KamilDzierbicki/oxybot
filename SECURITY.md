# Security policy

Please do not open a public issue for a vulnerability. Report it privately through the repository's security
advisories ("Report a vulnerability") with the steps to reproduce and the impact.

We especially want to hear about:

- data from one account visible to another account (tenancy leaks)
- ways to make the agent act on instructions hidden in customer feedback (prompt injection with an effect)
- forged or replayed webhooks (Slack, Mattermost, Linear) that are accepted
- tokens or secrets exposed in logs, pages or model requests

You will get an answer within a week. Fixes for confirmed issues are released before the details are published.
